Entry for the make.fun bounty "Sum up 18 November's world news in one image". `entry.png` is a 1024×1024 newspaper front page, "WEDNESDAY 18 NOVEMBER 2026", with six stories that defined the day, each with its own scene picture, kicker, headline and one-line summary: Trump lands in Manila for Quad talks ahead of a China visit; Ukraine strikes the Kerch bridge a second straight day as Russia pounds Kyiv bridges; Cyclone Akvan bears down on the Bay of Bengal; MS Dhoni, 45, retires as a player and becomes CSK mentor; Britain sanctions Israeli settlement firms to defend the two-state solution; the EU plans a €45bn loan to cover Ukraine's budget gap. All stories were reported on 18 November 2026 (Reuters, CNN, AP, BBC, Financial Times, IMD). Scene pictures are AI-generated illustrations (no text in them); all headlines, the date and labels are real text drawn onto the page, so the image reads cleanly at small sizes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). No network access; both runs write identical bytes.
