# news-image-20261118 — The World Today

One image summing up the world news of **Wednesday 18 November 2026**,
as a newspaper front page with six stories:

1. **Trump lands in Manila** — US president arrives for Quad talks ahead of a China visit.
2. **Crimea bridge hit again** — Ukraine strikes the Kerch bridge; Russia pounds Kyiv bridges.
3. **Cyclone Akvan bears down** — storm over the Bay of Bengal set to turn severe by 19 Nov.
4. **Dhoni calls time on IPL** — MS Dhoni, 45, retires as a player; CSK name him team mentor.
5. **Britain sanctions settlements** — UK sanctions Israeli settlement firms to defend the two-state solution.
6. **EU plans €45bn Ukraine loan** — Brussels to borrow billions to cover Kyiv's budget gap.

Sources: Reuters, CNN, AP, BBC, Financial Times, IMD.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `entry.png` (1024×1024 PNG) to the output directory. Deterministic:
both runs write identical bytes.
